# FL Studio Mobile 汉化与主题美化

一个基于 Frida 注入的 **FL Studio Mobile (FLM) 汉化与美化工程**，提供全面中文汉化、马卡龙主题配色，以及一个可爱的"请小猫喝冰红茶"赞赏弹窗功能。

| **原版英文版** | 保持英文界面（含中日文字库）+ 马卡龙主题 + 赞赏弹窗 | 同上（网盘内两个文件） |

## ✨ 功能特性

### 🌐 全面汉化（仅汉化版）
- **813 条翻译**，覆盖全部主要界面
- 主界面、文件浏览器、通道机架、混音器、设置、导出对话框
- 音阶选择器（34 种音阶）、效果器面板、钢琴卷帘工具
- 支持空格匹配、面包屑路径分段翻译
- 智能保留：音色名、文件格式名、音乐风格名保持英文（避免找不到对应音色）

### 🎨 马卡龙主题（两个版本都有）
替换 4 个内置主题为马卡龙色系：

| 主题 | 配色 |
|------|------|
| 薰衣草（替换 Paper） | 柔和的薰衣草紫色系 |
| 黑白主题（替换 Clay） | 经典黑白灰 |
| 薄荷马卡龙（替换 Ground） | 清新薄荷绿色系 |
| 粉色马卡龙（替换 Mint） | 甜美粉红色系 |

切换路径：设置 → Theme（主题）

### 🐱 赞赏弹窗（两个版本都有）
启动时弹出可爱的捐赠提示：
- **标题**：此软件完全免费
- **内容**：你是否愿意给作者(小猫)一些捐赠？例如请小猫喝杯冰红茶
- **勾选**「当天不再提示」→ 当天不再弹出
- 点击「我愿意」→ 选择 **微信 / 支付宝** → 显示对应收款码
- 支持**保存二维码**到相册
- 点击「我已赞赏」→ **7 天内**不再弹出
- 状态持久化，重启应用不丢失

## 🛠️ 安装说明

1. 卸载已安装的原版 FL Studio Mobile（显示签名不一致）
2. 安装下载的 APK
3. 首次启动请授予 **存储权限**（用于保存二维码）
4. 打开应用即可体验

> ⚠️ 安装时若提示"未知来源"，请开启"允许安装未知应用"
