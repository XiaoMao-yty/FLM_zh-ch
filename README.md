## 🔬 汉化原理（简版）

采用 **Frida 运行时动态汉化**：
1. 将 frida-gadget 注入 APK，应用启动时自动加载
2. 逆向定位所有文字绘制必经的底层函数（DrawTextUTF32 / RenderText）
3. 在文字画到屏幕前，实时把英文替换成中文
4. 不需要修改应用本体文件，稳定高效

> 简单说：给 FLM 请了个"实时翻译官"，文字显示前就被换成中文了。
